# سكني (Sakani) - تطبيق تأجير الشقق السكنية الفاخرة

تطبيق عقاري متكامل يربط بين أصحاب العقارات والمستأجرين، مبني بتقنيات **Flutter** الحديثة ومعمارية **Clean Code** مع دعم التشفير الشامل **AES-256**.

---

## 1. المميزات الرئيسية

### نظام المستخدمين والأمان
- تسجيل دخول وإنشاء حساب مشفر وآمن.
- تحديد نوع الحساب: **مستأجر (Tenant)** أو **مالك عقار (Owner)**.
- إدارة الجلسات والتوكنات بالتشفير المتطور AES-256.

### واجهة المستأجر
- **استكشاف الشقق**: تصفح الشقق المتاحة مع فلترة سريعة حسب المدينة والحد الأقصى للسعر.
- **تفاصيل الشقة**: صور بدقة عالية، عنوان، مساحة، عدد الغرف والحمامات، قائمة المرافق، والأسعار.
- **نظام الحجز**: حساب دقيق للتكلفة والعمولة ومبلغ التأمين المسترد.
- **حجوزاتي**: متابعة فورية لحالة الحجز (قيد الانتظار، مقبول، مرفوض، نشط، مكتمل).
- **المحادثات المباشرة**: تواصل فوري مع أصحاب العقارات.

### واجهة صاحب العقار
- **لوحة التحكم (Dashboard)**: إحصائيات مالية، عدد العقارات، الحجوزات النشطة، وإجمالي الأرباح.
- **إضافة عقار**: رفع صور العقار وتحديد الأسعار (يومي/شهري/سنوي) والمرافق.
- **إدارة طلبات الحجز**: قبول أو رفض الحجوزات وتحديث حالتها بضغطة زر.

## 2. التقنيات والمعمارية

| التقنية | الاستخدام |
|---------|-----------|
| **Flutter 3.44+** | إطار العمل الأساسي للواجهات |
| **Dart 3.12+** | لغة البرمجة الأساسية |
| **Provider** | إدارة الحالة (State Management) |
| **AES-256 & SHA-256** | محرك التشفير وفحص سلامة الملفات |
| **SecureStorageService** | تخزين الجلسات والتوكنات مشفرة محلياً |
| **REST API Engine** | تبادل البيانات مع الخادم عبر HTTP/HTTPS |
| **ProGuard / R8** | تعتيم الكود وحماية الملفات من الهندسة العكسية |

## 3. هيكلية المشروع (Clean Architecture)

```
sakani_app/
├── lib/
│   ├── main.dart                          # نقطة الدخول وتهيئة الجلسات المشفرة
│   ├── core/
│   │   ├── config/                        # إعدادات الـ API، الثيمات، والثوابت
│   │   ├── localization/                  # دعم اللغتين العربية والإنجليزية
│   │   ├── security/                      # محرك التشفير AES-256 والمخزن الآمن
│   │   └── widgets/                       # مكونات الواجهة القابلة لإعادة الاستخدام
│   └── features/
│       ├── auth/                          # إدارة المصادقة والمستخدمين
│       ├── apartments/                    # إدارة واستعراض الشقق ولوحة التحكم
│       ├── bookings/                      # إدارة الحجوزات والعمليات المالية
│       ├── chat/                          # نظام المحادثات المباشرة
│       └── settings/                      # إدارة الإعدادات والملف الشخصي
├── android/                               # إعدادات حماية أندرويد وتعتيم R8
└── test/                                  # اختبارات الوحدة واختبارات التشفير
```
